# Mercury Instructions
## Data Types and Bindings
Run ```mmc --make mercury_data_types_or_binding``` in ubuntu to compile
Run ```./mercury_data_types_or_binding``` in ubuntu

## Control Structures
Run ```mmc --make mercury_control_structures```
Run ```./mercury_control_structures```

# Data Types and Binding Explanation
Comparing Mercury and Scala in this example shows how each language handles data types and variable bindings. Both use static typing and inference but Scala allows reassignment of the variables using the var keyword while Mercury only have single assignment bindings to variables.

# Control Structures Explanation
Comparing Mercury and Scala in this example demostrates how Scala and Mercury with the same assignment, handles decisions diffeently. This example shows how Scala uses constructs like if/else, match, for and while, while Mercury uses conditional goals, pattern matching and recursion
